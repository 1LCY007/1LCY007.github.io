OpenGRAIL: Open-World Task Grouping and Robot Allocation with Integrated LLM Planning

Lead ResearcherSupervisor: Prof. Zhongkui Li

OpenGRAIL combines LLM-based hierarchical task planning with optimization-based robot allocation. It turns natural-language instructions, environment context, and robot capabilities into dependency-aware task groups and integrates their solutions into globally executable plans for large-scale, long-horizon tasks.

LLM-Based Planning Task Grouping Robot Allocation MILP Scheduling AI2-THOR Open-world Planning
  • Dependency-aware task grouping Developed an LLM-based hierarchical planner that interprets instructions, environment context, and robot capabilities to generate coordinated task groups.
  • Constrained allocation and scheduling Formulated heterogeneous robot allocation within each group as a mixed-integer linear program under capability, temporal, spatial, and collaboration constraints.
  • Globally executable plans Integrated group-level solutions to reduce planning time and improve planning accuracy at scale.

MemoSync: Co-Managing Developer-Agent Metamemory Across Contexts

Research AssistantSupervisor: Prof. Xiaojuan Ma

MemoSync turns an AI coding agent's memory into a shared representation that developers can inspect and control. The agent proposes reusable memories, while the developer reviews, edits, and assigns them to Personal, Project, or Session scopes to preserve intent across long-horizon collaboration.

Human-AI Interaction Agent Memory Memory Co-Management Coding Agents
  • Context and intent in long-horizon interactions Investigated how AI agents maintain task context, user intent, and reusable knowledge during long-horizon interactions.
  • Memory representation design Studied existing agent memory mechanisms and contributed to the conceptual design of memory representations and workflow structures.
  • Evaluation Designed evaluation scenarios and comparison experiments to analyze the impact of memory organization strategies on task completion, consistency, and knowledge reuse.

Course Project / Peking University

RepoFlow: Repository-Level Workflow for AI Coding Agents

RepoFlow is a course project exploring persistent context and structured agent handoff for long-horizon coding workflows. Its skill-based repository framework helps coding agents preserve project knowledge, coding conventions, and task continuity across sessions and agent transitions.

Coding Agents Claude Code Codex Agent Handoff Style Learning Code Health Review Repository Scaffold
View RepoFlow on GitHub Course Report (PDF)
  • Repository governance framework Designed and implemented a skill-based framework that encodes project structure, coding conventions, and review policies.
  • Agent handoff and style learning Developed mechanisms for structured handoff, shared context, and repo-local style learning to reduce drift across agent turns.
  • Code health review Built review logic for detecting patch-like naming, duplicate helpers, wrapper functions, suspicious files, and repository degradation.
