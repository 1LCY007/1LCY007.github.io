Sept. 2025 - Present

OpenGRAIL: Scalable Open-World Multi-Robot Planning via Grouped Reasoning, Allocation, and Inter-LLM Coordination

OpenGRAIL develops a scalable planning architecture that groups robots and tasks, coordinates specialized LLM reasoning, and triggers local-to-global recovery when the environment changes. AI2-THOR is used for simulation and task-allocation evaluation.

Currently under development.

Grouped Reasoning Robot Allocation Inter-LLM Coordination Dynamic Recovery AI2-THOR Open-world Planning
  • Manager layer Interprets natural-language tasks, groups robots, and maintains global environment and task state.
  • Group and planner layers Uses group-level reasoning, hierarchical task generation, motion planning, and plan-to-code execution.
  • Multi-level recovery Coordinates local LLM, group chat, planner-level, and manager-level recovery for dynamic environments.

Mar. 2026 - Present / Agent Systems

RepoFlow: Repository Workflow for AI Coding Agents

RepoFlow is a skill-based repository governance framework for LLM coding agents such as Claude Code and Codex. It focuses on preserving repository structure, style consistency, and handoff quality during long-term agent-assisted development.

Coding Agents Claude Code Codex Agent Handoff Style Learning Code Health Review Repository Scaffold
View RepoFlow on GitHub
  • Repository governance framework Designed and implemented a skill-based framework that encodes project structure, coding conventions, and review policies.
  • Agent handoff and style learning Developed mechanisms for structured handoff, shared context, and repo-local style learning to reduce drift across agent turns.
  • Code health review Built review logic for detecting patch-like naming, duplicate helpers, wrapper functions, suspicious files, and repository degradation.
